# Maze Game

Простая 2D-игра-лабиринт, разработанная на **Python** с использованием **Pygame** и **pygame-menu**. Игроку необходимо пройти лабиринт, избегая врагов и добраться до выхода. Проект также включает редактор и генератор лабиринтов.

## Возможности

- 🎮 Главное меню игры
- 🗺️ Несколько уровней
- 🧩 Генерация случайных лабиринтов
- ✏️ Редактор лабиринтов
- 🖼️ Конвертация лабиринтов из PNG
- 👾 Враги с поиском пути
- ❤️ Система жизней
- 🛒 Магазин

- 🔊 Музыка и звуковые эффекты
- 📈 Система прогресса между уровнями

## Установка

### 1. Клонирование репозитория

```bash
git clone https://github.com/<username>/DiplomGame.git
cd DiplomGame
```

### 2. Установка зависимостей

```bash
pip install pygame pygame-menu
```

## Особенности проекта

### Генерация лабиринтов

Игра умеет создавать случайные лабиринты, что делает каждое прохождение уникальным.

### Поиск пути

Для перемещения противников используется отдельный модуль поиска пути (`Pathfinder.py`).

### Редактор лабиринтов

Позволяет создавать собственные игровые карты.

### Конвертация изображений

Модуль `ConvertMazeFromPng.py` позволяет преобразовывать PNG-изображения в игровые карты.
